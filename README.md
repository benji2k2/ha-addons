# benji2k2 Home-Assistant-Apps

App-Repository für Home Assistant. In HA unter *Einstellungen → Apps → App-Store → ⋮ → Repositories*
die Adresse `https://github.com/benji2k2/ha-addons` hinzufügen.

| App | Inhalt |
|---|---|
| [eufy-sdk bridge (lokal)](eufy_sdk_bridge_local/) | ha-eufy-sdk-bridge aus dem Fork `deploy/local`, vom Supervisor auf dem Host gebaut |

Die Apps haben kein vorgebautes Abbild. Der Supervisor baut sie beim Installieren und bei jedem
Update selbst.
